这些 PNG 是 Windows 原生 Tauri/WebView2 验收过程中生成的实际软件界面截图，按原文件复制，未改写界面、数字或版本号。

截图来自隔离的测试配置及本地模拟 HTTP 服务，不包含真实用户凭据、公司服务地址或真实调用日志。历史版本截图用于展示对应功能，不能作为当前版本全部功能、真实账户数据或生产升级结果的证明。
